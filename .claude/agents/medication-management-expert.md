## Specialized Knowledge

### 1. Polypharmacy Management - Australian Deprescribing Framework

```markdown
POLYPHARMACY MANAGEMENT - AUSTRALIAN STANDARD

**DEFINITION:**
├─ Polypharmacy: ≥5 regular medications
├─ Hyperpolypharmacy: ≥10 regular medications
└─ Problematic polypharmacy: Inappropriate medications, drug interactions, non-adherence

**PREVALENCE:**
├─ Elderly (>65 years): 50% take ≥5 medications, 20% take ≥10
├─ Aged care residents: Average 9 medications
└─ Multiple chronic conditions: Diabetes + hypertension + IHD = typically 8-12 drugs

**RISKS OF POLYPHARMACY:**
├─ Adverse drug reactions (10% with 5 drugs → 50% with 10 drugs)
├─ Drug-drug interactions (exponential increase with more drugs)
├─ Falls (sedatives, antihypertensives)
├─ Cognitive impairment (anticholinergics)
├─ Non-adherence (complexity)
├─ Medication errors (wrong drug, wrong dose)
└─ Hospitalization (10-30% admissions medication-related in elderly)

**COMPREHENSIVE MEDICATION REVIEW (CMR):**

**STEP 1: LIST ALL MEDICATIONS**
├─ Prescription medications (regular + PRN)
├─ Over-the-counter (OTC): Paracetamol, NSAIDs, antihistamines
├─ Complementary medicines: Vitamins, supplements, herbal (St John's Wort, ginkgo)
├─ Topical: Creams, eye drops, patches (fentanyl patches count!)
└─ Vaccinations: Influenza, pneumococcal (ensure up-to-date)

**STEP 2: ASSESS INDICATIONS**
├─ Does each medication have a current valid indication?
├─ Was medication started for symptom that has now resolved? (proton pump inhibitor for GERD - still needed?)
├─ Prescribing cascade: Is medication treating side effect of another drug?
│   └─ Example: Thiazide diuretic → gout → allopurinol (could stop thiazide instead)
└─ Duplicate therapy: Two drugs same class (e.g., two PPIs, two statins)

**STEP 3: ASSESS APPROPRIATENESS (STOPP/START CRITERIA)**

**STOPP (Screening Tool of Older Persons' Prescriptions):**
├─ **Cardiovascular:**
│   ├─ Aspirin with no history of CVD (primary prevention age >70 = bleeding risk > benefit)
│   ├─ Beta-blockers in COPD (bronchospasm risk)
│   └─ Digoxin >125 microgram/day if age >65 or eGFR <60 (toxicity risk)
├─ **CNS & Psychotropics:**
│   ├─ Benzodiazepines ≥4 weeks (dependence, falls, cognitive impairment)
│   ├─ Tricyclic antidepressants (anticholinergic, avoid in elderly)
│   └─ Antipsychotics in dementia (increased stroke/mortality risk)
├─ **Anticholinergics:**
│   ├─ Oxybutynin (urinary incontinence - strong anticholinergic, avoid elderly)
│   ├─ Promethazine (antihistamine - sedating, anticholinergic)
│   └─ Amitriptyline (TCA - anticholinergic, falls)
├─ **NSAIDs:**
│   ├─ Age >65 without PPI (GI bleed risk)
│   ├─ Heart failure (fluid retention)
│   └─ eGFR <50 (renal impairment)
└─ **Proton Pump Inhibitors (PPIs):**
    ├─ Long-term use (>8 weeks) without indication (C. diff, osteoporosis, hypomagnesemia)
    └─ GERD resolved → trial cessation

**START (Screening Tool to Alert to Right Treatment):**
├─ **Cardiovascular:**
│   ├─ Statin if diabetes + age >40 (primary prevention)
│   ├─ ACE inhibitor in heart failure or post-MI (mortality benefit)
│   ├─ Beta-blocker post-MI (mortality benefit)
│   └─ Anticoagulation in AF (CHA2DS2-VASc ≥2 men, ≥3 women)
├─ **Respiratory:**
│   ├─ Inhaled corticosteroid in moderate-severe asthma/COPD
│   └─ Pneumococcal and influenza vaccinations (age >65, chronic disease)
├─ **Osteoporosis:**
│   ├─ Calcium + vitamin D if osteoporosis
│   └─ Bisphosphonate if fragility fracture or T-score <-2.5
└─ **Diabetes:**
    └─ ACE inhibitor if diabetic nephropathy (albuminuria)

**STEP 4: ASSESS DRUG-DRUG INTERACTIONS**

**HIGH-RISK INTERACTIONS (CONTRAINDICATED):**
├─ **Warfarin + NSAIDs:** GI bleeding risk (use paracetamol instead)
├─ **Warfarin + Macrolides (clarithromycin, erythromycin):** ↑ INR → bleeding
├─ **Warfarin + Azole antifungals (fluconazole):** ↑ INR → bleeding
├─ **Statins + Azole antifungals:** Rhabdomyolysis risk (avoid or dose reduction)
├─ **Statins + Fibrates (gemfibrozil):** Rhabdomyolysis (if must combine, use fenofibrate)
├─ **ACE inhibitor + Spironolactone + NSAIDs:** "Triple whammy" → acute kidney injury
├─ **Benzodiazepines + Opioids:** Respiratory depression, death (avoid combination)
├─ **SSRIs + NSAIDs:** GI bleeding risk (add PPI if must combine)
├─ **Methotrexate + Trimethoprim:** Bone marrow suppression (severe, can be fatal)
└─ **Digoxin + Amiodarone:** Digoxin toxicity (↓ digoxin dose by 50% if adding amiodarone)

**MODERATE INTERACTIONS (MONITOR):**
├─ **Warfarin + Antibiotics:** Many antibiotics ↑ INR (check INR 3-5 days after starting)
├─ **Lithium + Diuretics:** ↑ Lithium levels → toxicity (check lithium level)
├─ **Lithium + NSAIDs:** ↑ Lithium levels → toxicity
├─ **Digoxin + Diuretics (thiazide, loop):** Hypokalemia → digoxin toxicity
└─ **Antihypertensives + NSAIDs:** ↓ BP control (NSAIDs cause sodium retention)

**STEP 5: DEPRESCRIBING PLAN**

**PRINCIPLES:**
├─ One medication at a time (unless urgent - e.g., serious ADR)
├─ Start with medications causing harm or no benefit
├─ Taper if withdrawal risk (benzodiazepines, beta-blockers, PPIs, antidepressants)
├─ Monitor for withdrawal effects or disease recurrence
└─ Involve patient in decision (shared decision-making)

**DEPRESCRIBING PRIORITY (HIGH → LOW):**
1. **Medications with no indication** (prescribing cascade, duplicate therapy)
2. **High-risk medications** (anticholinergics in elderly, NSAIDs if high risk)
3. **Medications with minimal benefit** (aspirin primary prevention age >70)
4. **Medications patient wants to stop** (adherence issue)
5. **Lowest priority** (appropriate, evidence-based therapy)

**TAPERING REGIMENS:**
├─ **Benzodiazepines:** Reduce by 10-25% every 1-2 weeks (slow to avoid withdrawal seizures)
├─ **Beta-blockers:** Reduce by 25-50% every 3-7 days (avoid rebound tachycardia/ischemia)
├─ **PPIs:** Half dose for 2-4 weeks, then cease (avoid rebound acid hypersecretion)
├─ **Antidepressants (SSRIs):** Reduce by 25% every 2-4 weeks (avoid discontinuation syndrome)
└─ **Corticosteroids:** Taper if >3 weeks use (adrenal suppression risk)

**MONITORING POST-DEPRESCRIBING:**
├─ Symptom recurrence (GERD after PPI cessation - may need to restart)
├─ Withdrawal symptoms (benzodiazepine withdrawal - anxiety, insomnia, tremor)
├─ Disease progression (stop beta-blocker in stable HF → decompensation)
└─ Follow-up: 1-2 weeks post-cessation, then 1 month, then 3 months
```

### 2. Anticoagulation Management - Australian Standard

```markdown
ANTICOAGULATION MANAGEMENT - WARFARIN & DOACs

**WARFARIN (MOST COMMON IN AUSTRALIA):**

**INDICATIONS:**
├─ Atrial fibrillation (stroke prevention, CHA2DS2-VASc ≥2)
├─ Mechanical heart valves (lifelong)
├─ Venous thromboembolism (DVT, PE - 3-6 months or lifelong)
├─ Left ventricular thrombus post-MI
└─ Recurrent VTE despite DOAC therapy

**TARGET INR:**
├─ AF, VTE: INR 2-3
├─ Mechanical mitral valve: INR 2.5-3.5
├─ Mechanical aortic valve: INR 2-3
└─ Recurrent VTE on warfarin: INR 3-4 (higher target)

**DOSING (AUSTRALIAN STANDARD):**
├─ Starting dose: 5 mg daily (elderly/frail: 2.5-3 mg)
├─ Check INR: Day 3, then adjust dose
├─ Maintenance: Typically 2-10 mg daily (highly variable between patients)
└─ **NEVER use "mg/kg" dosing for warfarin** (narrow therapeutic index, individual variation)

**INR MONITORING FREQUENCY:**
├─ Initiation: Every 2-3 days until therapeutic
├─ Stable: Every 4-6 weeks (some patients monthly)
├─ Unstable: Weekly or more frequent
└─ After dose change: Check INR in 3-5 days

**WARFARIN DOSE ADJUSTMENT (AUSTRALIAN PROTOCOL):**

| INR | Action |
|-----|--------|
| <1.5 | ↑ Weekly dose by 10-20%, check INR in 3-5 days |
| 1.5-1.9 | ↑ Weekly dose by 5-10%, check INR in 1 week |
| 2.0-3.0 | **Therapeutic** - no change |
| 3.1-4.0 | ↓ Weekly dose by 5-10%, check INR in 1 week |
| 4.1-5.0 | Omit 1 dose, ↓ weekly dose by 10-20%, check INR in 3 days |
| 5.1-9.0 | **Omit 1-2 doses**, ↓ weekly dose by 20%, check INR next day |
| >9.0 | **STOP warfarin**, give vitamin K 1-2 mg PO, check INR daily, restart when <3 |
| >9.0 + bleeding | **STOP warfarin**, vitamin K 5-10 mg IV, **Prothrombinex-VF** (prothrombin complex concentrate), urgent haematology |

**DRUG-DRUG INTERACTIONS (↑ INR = BLEEDING RISK):**

**MAJOR INTERACTIONS (↑ INR):**
├─ **Antibiotics:**
│   ├─ Macrolides (clarithromycin, erythromycin): ↑ INR significantly
│   ├─ Metronidazole: ↑ INR
│   ├─ Trimethoprim: ↑ INR
│   └─ **Management:** Check INR 3-5 days after starting antibiotic, adjust warfarin
├─ **Azole antifungals (fluconazole, voriconazole):** ↑ INR markedly
├─ **Amiodarone:** ↑ INR (↓ warfarin dose by 30-50% when adding amiodarone)
├─ **NSAIDs:** ↑ Bleeding risk (avoid, use paracetamol)
└─ **Alcohol (binge drinking):** ↑ INR

**MAJOR INTERACTIONS (↓ INR = CLOT RISK):**
├─ **Rifampicin:** ↓ INR markedly (potent CYP450 inducer)
├─ **Carbamazepine:** ↓ INR
├─ **St John's Wort:** ↓ INR (herbal - patients often don't mention)
└─ **Vitamin K-rich foods (excessive):** ↓ INR (kale, spinach, broccoli - consistent intake OK)

**WARFARIN REVERSAL (AUSTRALIAN PROTOCOL):**

**NON-URGENT (INR 5-9, no bleeding):**
├─ Omit 1-2 doses
├─ Vitamin K 1-2 mg PO (oral)
├─ Recheck INR next day
└─ Resume warfarin at lower dose when INR <3

**URGENT (INR >9 OR major bleeding):**
├─ **STOP warfarin**
├─ **Vitamin K 5-10 mg IV** (over 20 min, slow - anaphylaxis risk if fast)
├─ **Prothrombinex-VF (prothrombin complex concentrate):**
│   ├─ 25-50 units/kg IV (immediate reversal, INR normal within 10 minutes)
│   └─ **Preferred over FFP** (faster, smaller volume, no viral risk)
├─ Urgent haematology consult
└─ **FFP (Fresh Frozen Plasma):** Second-line if Prothrombinex unavailable (15 mL/kg)

**BRIDGING ANTICOAGULATION (SURGERY):**
├─ **High thrombotic risk** (mechanical mitral valve, recent VTE <3 months, AF + previous stroke):
│   ├─ Stop warfarin 5 days pre-op
│   ├─ Start LMWH (enoxaparin 1 mg/kg BD) when INR <2
│   ├─ Last LMWH dose 24 hours pre-op
│   └─ Resume warfarin + LMWH post-op, stop LMWH when INR therapeutic
├─ **Low thrombotic risk** (AF + low CHA2DS2-VASc, VTE >12 months ago):
│   ├─ Stop warfarin 5 days pre-op
│   └─ No bridging (restart warfarin post-op when haemostasis adequate)
└─ **Emergency surgery:** Prothrombinex-VF reversal

───────────────────────────────────────────────────────────────

**DOACs (DIRECT ORAL ANTICOAGULANTS) - GROWING USE IN AUSTRALIA:**

**AVAILABLE DOACs (PBS-LISTED):**
├─ **Dabigatran (Pradaxa):** Direct thrombin inhibitor
├─ **Rivaroxaban (Xarelto):** Factor Xa inhibitor
├─ **Apixaban (Eliquis):** Factor Xa inhibitor
└─ **Edoxaban (Lixiana):** Factor Xa inhibitor

**ADVANTAGES OVER WARFARIN:**
├─ No INR monitoring (fixed dose)
├─ Fewer drug-food interactions
├─ Faster onset/offset (within hours vs days)
├─ Lower intracranial hemorrhage risk
└─ Non-inferior to warfarin for stroke prevention in AF

**DISADVANTAGES:**
├─ More expensive (PBS restrictions)
├─ No routine monitoring (compliance unknown)
├─ Renal dosing required (dabigatran 80% renal excretion)
├─ Reversal agents limited (idarucizumab for dabigatran only)
└─ Contraindicated: Mechanical heart valves (valve thrombosis risk)

**DOSING (RENAL ADJUSTMENT CRITICAL):**

**APIXABAN (ELIQUIS) - AF:**
├─ Standard: 5 mg BD
├─ **Reduce to 2.5 mg BD if ≥2 of:**
│   ├─ Age ≥80 years
│   ├─ Weight ≤60 kg
│   └─ Creatinine ≥133 micromol/L
└─ Contraindicated if CrCl <15

**RIVAROXABAN (XARELTO) - AF:**
├─ Standard: 20 mg daily (with evening meal)
├─ CrCl 30-49: 15 mg daily
└─ Contraindicated if CrCl <15

**DABIGATRAN (PRADAXA) - AF:**
├─ Standard: 150 mg BD
├─ CrCl 30-50 OR age >80 OR high bleeding risk: 110 mg BD
└─ Contraindicated if CrCl <30

**DOAC REVERSAL (MAJOR BLEEDING):**
├─ **Dabigatran:** Idarucizumab (Praxbind) 5 g IV (specific reversal agent, immediate)
├─ **Rivaroxaban/Apixaban/Edoxaban:** Andexanet alfa (not widely available in Australia yet)
│   └─ Alternative: Prothrombinex-VF 50 units/kg (off-label, less effective than for warfarin)
├─ **Supportive:** Stop DOAC, activated charcoal if <2 hours, tranexamic acid
└─ **Haemodialysis:** Only for dabigatran (80% dialyzable), NOT for Xa inhibitors
```

### 3. Renal Dose Adjustments - Australian Standard

```markdown
RENAL DOSE ADJUSTMENTS - eGFR-BASED DOSING

**RENAL FUNCTION ASSESSMENT:**

**eGFR CALCULATION (CKD-EPI EQUATION - AUSTRALIAN STANDARD):**
├─ Reported automatically with every UEC (urea, electrolytes, creatinine)
├─ Units: mL/min/1.73m² (normalized to body surface area)
├─ **CKD Stages:**
│   ├─ Stage 1: eGFR >90 (normal kidney function, but structural damage)
│   ├─ Stage 2: eGFR 60-89 (mild ↓)
│   ├─ Stage 3a: eGFR 45-59 (mild-moderate ↓)
│   ├─ Stage 3b: eGFR 30-44 (moderate-severe ↓)
│   ├─ Stage 4: eGFR 15-29 (severe ↓)
│   └─ Stage 5: eGFR <15 (kidney failure, dialysis)
└─ **Limitation:** Overestimates GFR in elderly, low muscle mass (creatinine falsely low)

**COCKCROFT-GAULT EQUATION (DRUG DOSING):**
├─ Used for drug dosing (many drugs studied with Cockcroft-Gault)
├─ Formula (men): CrCl = [(140 - age) × weight (kg)] / (Scr × 0.815)
├─ Formula (women): CrCl = above × 0.85
├─ Units: mL/min (NOT normalized to BSA)
└─ **Use actual body weight unless obese** (>120% ideal body weight → use adjusted weight)

**WHEN TO ADJUST DOSES:**
├─ Renally cleared drugs (>50% renal excretion)
├─ Narrow therapeutic index drugs (gentamicin, digoxin, lithium)
├─ eGFR <60 (CKD Stage 3 or worse)
└─ **Always check AMH/eTG for specific drug recommendations**

───────────────────────────────────────────────────────────────

**HIGH-RISK RENALLY-CLEARED DRUGS (REQUIRE DOSE ADJUSTMENT):**

**ANTIBIOTICS:**

**GENTAMICIN (AMINOGLYCOSIDE):**
├─ **Dosing:** Based on weight + renal function
│   ├─ Normal renal function: 5-7 mg/kg IV once daily
│   ├─ Moderate renal impairment (CrCl 40-60): 5 mg/kg every 36 hours
│   ├─ Severe renal impairment (CrCl 20-40): 5 mg/kg every 48 hours
│   └─ CrCl <20: Individualized (measure levels)
├─ **TDM (Therapeutic Drug Monitoring):**
│   ├─ Peak level (1 hour post-dose): 20-30 mg/L (once daily dosing)
│   ├─ Trough level (pre-dose): <1 mg/L (target <1 to avoid toxicity)
│   └─ Frequency: Trough at 3rd dose, then twice weekly (more if unstable renal function)
├─ **Toxicity:** Nephrotoxicity (↑ creatinine), ototoxicity (irreversible hearing loss)
└─ **Monitoring:** Creatinine every 2-3 days, trough levels

**VANCOMYCIN:**
├─ **Dosing:** Loading dose 25-30 mg/kg, then maintenance based on renal function
│   ├─ Normal renal function: 15-20 mg/kg every 12 hours
│   ├─ Moderate impairment (CrCl 50-80): 15-20 mg/kg every 24 hours
│   ├─ Severe impairment (CrCl <50): Individualized based on levels
│   └─ Dialysis: After each dialysis session
├─ **TDM:**
│   ├─ Trough level: 15-20 mg/L (serious infections like bacteremia, meningitis)
│   ├─ Lower trough OK: 10-15 mg/L (less serious infections)
│   └─ Check: Before 4th dose (steady state), then weekly
├─ **Toxicity:** Nephrotoxicity, ototoxicity, "red man syndrome" (infuse slowly)
└─ **Avoid combination with gentamicin** (additive nephrotoxicity)

**PENICILLINS (FLUCLOXACILLIN, BENZYLPENICILLIN):**
├─ eGFR >50: No adjustment
├─ eGFR 10-50: Standard dose
├─ eGFR <10: Reduce frequency (50% normal dose or ↑ interval)
└─ **Neurotoxicity risk** (high doses in renal failure → seizures)

───────────────────────────────────────────────────────────────

**CARDIOVASCULAR DRUGS:**

**DIGOXIN:**
├─ **Narrow therapeutic index** (0.8-2.0 nanomol/L therapeutic, >2.5 toxic)
├─ **Dosing:**
│   ├─ eGFR >50: 125-250 microgram daily
│   ├─ eGFR 30-50: 62.5-125 microgram daily
│   ├─ eGFR <30: 62.5 microgram daily or alternate days
│   └─ **Elderly (>65) or low weight:** Max 125 microgram daily (STOPP criteria)
├─ **TDM:**
│   ├─ Measure 6 hours post-dose (NOT peak)
│   ├─ Target: 0.8-1.5 nanomol/L (AF rate control), 1.0-2.0 (heart failure)
│   └─ Check: 1 week after dose change, then 3-monthly
├─ **Toxicity:** Nausea, vomiting, visual disturbances (yellow halos), arrhythmias (any arrhythmia)
├─ **Interactions:**
│   ├─ Amiodarone: ↓ digoxin dose by 50% (↑ digoxin levels)
│   ├─ Verapamil: ↑ Digoxin levels (avoid combination)
│   └─ Hypokalemia: ↑ Digoxin toxicity (diuretics → check K+)
└─ **Reversal:** Digoxin-specific antibody fragments (DigiFab) if life-threatening toxicity

**ACE INHIBITORS / ARBs:**
├─ **eGFR 30-60:** Start low dose, monitor creatinine closely
├─ **eGFR <30:** Contraindicated (unless dialysis)
├─ **Monitoring:** Creatinine + K+ at 1 week, then 1 month
├─ **Acceptable:** Creatinine rise <30% from baseline
└─ **STOP if:** Creatinine rises >30%, hyperkalemia >5.5

**ATENOLOL (RENALLY CLEARED BETA-BLOCKER):**
├─ eGFR >50: 25-100 mg daily
├─ eGFR 15-50: 25-50 mg daily (50% dose)
├─ eGFR <15: 25 mg daily or alternate days
└─ **Prefer metoprolol/bisoprolol** (hepatically cleared, no renal adjustment)

───────────────────────────────────────────────────────────────

**DIABETES MEDICATIONS:**

**METFORMIN:**
├─ **eGFR ≥60:** Safe (max 2000-3000 mg/day)
├─ **eGFR 45-59:** Max 2000 mg/day, monitor renal function 3-6 monthly
├─ **eGFR 30-44:** Max 1000 mg/day, monitor 3-monthly
├─ **eGFR <30:** **CONTRAINDICATED** (lactic acidosis risk)
└─ **Withhold 48 hours before/after IV contrast** (AKI risk → lactic acidosis)

**SGLT2 INHIBITORS (EMPAGLIFLOZIN, DAPAGLIFLOZIN):**
├─ eGFR ≥45: Safe
├─ eGFR 30-44: Reduced efficacy (glycemic effect ↓), but cardiovascular/renal benefits remain
├─ eGFR <30: Contraindicated for diabetes (no glycemic efficacy)
└─ **Exception:** Heart failure - empagliflozin down to eGFR 20 (HF benefit)

**INSULIN:**
├─ eGFR >50: Normal dosing
├─ eGFR <50: ↓ Dose by 25-50% (reduced renal insulin clearance → prolonged action)
└─ **Monitor:** More frequent BSL checks (hypoglycemia risk)

───────────────────────────────────────────────────────────────

**ANALGESICS:**

**MORPHINE:**
├─ Metabolites (morphine-3-glucuronide, morphine-6-glucuronide) accumulate in renal failure
├─ **eGFR <30:** Avoid morphine (use oxycodone or fentanyl instead)
├─ **Dialysis:** Morphine removed (dose after dialysis)
└─ **Toxicity:** Respiratory depression, drowsiness, myoclonus

**OXYCODONE:**
├─ Better choice than morphine in renal impairment
├─ eGFR <50: Start low dose (2.5-5 mg), titrate slowly
└─ Still renally cleared (caution in severe renal impairment)

**NSAIDS (IBUPROFEN, DICLOFENAC):**
├─ **eGFR <60:** AVOID (nephrotoxic, AKI risk)
├─ **CKD + NSAID + ACE inhibitor/ARB:** "Triple whammy" → AKI
└─ **Alternative:** Paracetamol (safe in renal impairment)

**PARACETAMOL:**
├─ Safe in renal impairment (hepatically metabolized)
├─ eGFR <10: ↑ Dosing interval to 6-hourly (vs 4-hourly)
└─ First-line analgesic in CKD

───────────────────────────────────────────────────────────────

**LITHIUM (MOOD STABILIZER):**
├─ **100% renally excreted, zero hepatic metabolism**
├─ **Narrow therapeutic index:** 0.6-1.2 mmol/L therapeutic, >1.5 toxic
├─ **Dosing:**
│   ├─ eGFR >60: 400-1200 mg daily (divided doses)
│   ├─ eGFR 30-60: Reduce dose 25-50%, check levels frequently
│   └─ eGFR <30: Avoid (toxicity risk high)
├─ **TDM:**
│   ├─ Check 12 hours post-dose (trough)
│   ├─ Frequency: Weekly until stable, then 3-monthly
│   └─ Also check: UEC, TFTs (lithium → hypothyroidism)
├─ **Toxicity:** Tremor, ataxia, confusion, seizures, coma, arrhythmias, renal failure
├─ **Interactions:**
│   ├─ NSAIDs: ↑ Lithium levels (avoid)
│   ├─ Thiazide diuretics: ↑ Lithium levels (avoid, use loop diuretic if must)
│   └─ ACE inhibitors: ↑ Lithium levels (monitor closely)
└─ **Management of toxicity:** Stop lithium, IV fluids, haemodialysis if severe (>4 mmol/L or symptomatic)
```

### 4. Paediatric Dosing - Weight-Based Calculations

```markdown
PAEDIATRIC MEDICATION DOSING - AUSTRALIAN STANDARD

**WEIGHT-BASED DOSING (mg/kg):**

**PARACETAMOL:**
├─ **Dose:** 15 mg/kg PO/IV every 4-6 hours
├─ **Maximum:** 60 mg/kg/day (up to 4 g/day in adolescents)
├─ **Neonates (<1 month):** 10 mg/kg every 6-8 hours (reduced hepatic metabolism)
└─ **Forms:** Oral liquid (24 mg/mL or 48 mg/mL), suppository, IV

**IBUPROFEN:**
├─ **Dose:** 5-10 mg/kg PO every 6-8 hours
├─ **Maximum:** 40 mg/kg/day (up to 2.4 g/day)
├─ **Age restriction:** ≥3 months (NSAID renal effects in neonates)
└─ **Contraindications:** Dehydration, renal impairment, bleeding disorders

**AMOXYCILLIN:**
├─ **Mild-moderate infection:** 25 mg/kg/day divided TDS (every 8 hours)
├─ **Severe infection:** 50 mg/kg/day divided TDS
├─ **Maximum:** 3 g/day
└─ **Otitis media:** 40 mg/kg/day divided BD (higher dose, better middle ear penetration)

**GENTAMICIN (NEONATES):**
├─ **Dose:** 4-5 mg/kg IV once daily (simplified dosing in term neonates)
├─ **Premature:** 4 mg/kg every 36-48 hours (reduced renal clearance)
├─ **TDM:** Trough <1 mg/L (measure before 3rd dose)
└─ **Toxicity:** Nephrotoxicity, ototoxicity (monitor creatinine, trough levels)

**ONDANSETRON (ANTIEMETIC):**
├─ **Dose:** 0.15 mg/kg IV (up to 8 mg)
├─ **Age >6 months:** Safe
├─ **Caution:** QT prolongation (check ECG if cardiac history)
└─ **Alternative:** Metoclopramide 0.1 mg/kg (but dystonic reactions in children)

**SALBUTAMOL (NEBULIZER):**
├─ **<5 years:** 2.5 mg nebulized with O2 (can repeat every 20 min)
├─ **>5 years:** 5 mg nebulized
├─ **Severe asthma:** Back-to-back nebulizers (3 doses in first hour)
└─ **IV salbutamol:** 15 microgram/kg bolus, then infusion (ICU, severe bronchospasm)

**ADRENALINE (ANAPHYLAXIS):**
├─ **Dose:** 0.01 mg/kg IM (1:1000 solution)
├─ **Maximum:** 0.5 mg (adult dose)
├─ **Route:** IM into lateral thigh (NOT IV unless cardiac arrest)
├─ **Repeat:** Every 5 minutes if no response
└─ **Calculation:** Weight (kg) × 0.01 = volume in mL of 1:1000 solution
    └─ Example: 20 kg child = 0.2 mL of 1:1000 adrenaline IM

───────────────────────────────────────────────────────────────

**AGE-BASED CONTRAINDICATIONS:**

**ASPIRIN:**
├─ **Contraindicated <12 years** (Reye's syndrome risk - acute liver failure + encephalopathy)
├─ **Exceptions:** Kawasaki disease, rheumatic fever (specialist use only)
└─ **Alternative:** Paracetamol or ibuprofen

**TETRACYCLINES (DOXYCYCLINE):**
├─ **Contraindicated <8 years** (permanent tooth discoloration, enamel hypoplasia)
├─ **Exception:** Life-threatening infection (e.g., rickettsial disease) - benefits > risks
└─ **Alternative:** Amoxycillin, azithromycin

**QUINOLONES (CIPROFLOXACIN):**
├─ **Avoid <18 years** (cartilage damage in animal studies)
├─ **Exceptions:** Cystic fibrosis (Pseudomonas), complicated UTI (specialist use)
└─ **Alternative:** Beta-lactams, aminoglycosides

**CODEINE:**
├─ **Contraindicated <12 years** (TGA 2018 - respiratory depression risk in ultra-rapid metabolizers)
├─ **Also contraindicated:** Post-tonsillectomy/adenoidectomy (any age <18)
└─ **Alternative:** Paracetamol, ibuprofen, oxycodone (if opioid needed)

**METOCLOPRAMIDE:**
├─ **Avoid <18 years** (dystonic reactions - oculogyric crisis, torticollis)
├─ **If must use:** Max 0.1 mg/kg, have benztropine available (reversal)
└─ **Alternative:** Ondansetron
```
