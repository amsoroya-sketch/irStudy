📋 Summary: How Quality System Works

🎯 Core Principle

"Prevention, Not Correction" - Catch quality issues BEFORE they're created, not after.

1️⃣ Quality Defined In

  • PROJECT_CONSTRAINTS_V3.md - Quick reference (Top 10 Critical Constraints)
  • constraints/1-medical-accuracy.md - Medical standards
  • constraints/4-llm-integration.md - LLM requirements (Section 4.2 critical)
  • constraints/3-security.md - Security standards
  • constraints/5-data-processing.md - Data handling
  • constraints/6-testing.md - Testing requirements

2️⃣ Quality Enforced By

  • Pre-generation: Agent reads constraints, RAG validates citations, LLM capability check
  • During generation: Claude generates realistic content with Australian context
  • Post-generation: validate_regenerated_mcqs.py runs 6 validation checks
  • Before commit: Manual checklist verification

3️⃣ Quality Maintained Through

  • Modular Constraint System: Easy to update specific sections without rewriting everything
  • Version Control: Git tracks all constraint changes with rationale
  • Automated Validation: Scripts can run on demand or as part of CI/CD
  • Historical Evidence: Week 3 regeneration serves as proof of concept and template
  • Documentation: This HTML document + REGENERATION_PROGRESS.md track quality metrics

4️⃣ Quality System Evolution

Version 2.0: Added Section 4.2 (LLM capabilities) after 200 MCQs failed
