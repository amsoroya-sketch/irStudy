3. Lessons Learned: 7 Critical Mistakes

Mistake #1: NOT Using Agent OS Medical Experts

What Happened: Generated content using generic OllamaClient instead of routing to specialty-specific medical expert agents (MED-001 through MED-010).

Impact: 1,508 MCQs with placeholder content, no specialty-specific tools applied (ECG interpretation, spirometry, MSE), generic clinical scenarios instead of specialty-specific presentations.

Why It Happened: Scripts delegated to general-purpose agent without explicit Agent OS requirement. Task prompt didn't specify "use MED-001 for cardiology MCQs". No specialty routing logic in generation scripts.

Mistake #2: Template-Based Generation (Violates Constraint 12)

What Happened: Scripts used string templates with placeholder text. Did NOT extract RAG citation content for LLM input. LLM never saw actual medical knowledge from citations.

Impact: 12,732 placeholder patterns detected:
- "Clinical scenario for..." (2,208 instances)
- "Question about..." (2,208 instances)
- "Option A/B/C/D" (8,832 instances)
- Zero educational value, clinical safety risk 
# WRONG (what we did):
scenario = f"Clinical scenario for {topic}"  # Template!
stem = f"Question about {topic}?"  # Template!
options = {"A": "Option A", "B": "Option B"}  # Template!

# RIGHT (what we should do):
citations = rag_query(topic)
citation_text = "\n\n".join([c['content'] for c in citations])
mcq = llm.generate(f"Generate MCQ using: {citation_text}")
Mistake #3: Insufficient Constraint Enforcement

What Happened:

  • Constraint 11 (3 citations per MCQ): Not enforced during generation. Some MCQs had 2 citations, some had 0.
  • Constraint 12 (LLM-powered): Not enforced. Template generation allowed.
Impact: 938 items from commit 0d7de50 unusable. Additional 1,270 items from Week 1-3 unusable. Total rework required: 2,208 MCQs.

Why It Happened: Constraints documented but not implemented as blocking gates. Generation scripts didn't validate constraints incrementally. Pre-commit hook created AFTER content generated (should be BEFORE).

Mistake #4: No Specialty Routing

What Happened: All MCQs generated with single generic approach. Cardiology MCQs didn't use ECG interpretation tools. Respiratory MCQs didn't use spirometry/CXR tools. Psychiatry MCQs didn't use MSE/risk assessment tools.

Impact: Lost opportunity for specialty-specific enhancements:
- Cardiology: No ECG images, no GRACE/TIMI scores
- Respiratory: No spirometry data, no CXR findings
- Psychiatry: No MSE format, no screening tools (PHQ-9, GAD-7)
Mistake #5: Post-Generation Validation (Should Be Pre + During)

What Happened: Validation scripts created AFTER 2,958 items generated. No incremental validation during generation. Placeholder content saved to git before detection.

Impact: Wasted 2-4 hours generating invalid content. 12MB of placeholder JSON files. 1 hour validating 33 files. Complete regeneration now required (2-4 hours more).
Mistake #6: No Summary Field (User Requirement)

What Happened: User explicitly requested summaries: "for mcq we need summary as well". Generated 750 valid MCQs WITHOUT summaries. Summaries added to plan but not to existing valid content.

Impact: 400 valid MCQs need updates (add summaries). 1,508 placeholder MCQs need full regeneration WITH summaries. Inconsistent MCQ structure across dataset.
Mistake #7: Duplicate Files (_with_images)

What Happened: Created duplicate files: week3_respiratory_200_mcqs.json AND week3_respiratory_200_mcqs_with_images.json. Both have identical placeholder content. Doubled placeholder count (1,508 → 2,208 when counting duplicates).

Impact: Inflated audit numbers (2,208 vs 1,508 unique MCQs). Extra validation time (12 files vs 7 unique files). Confusion about actual scope.

citations = rag_query(topic="myocardial_infarction", limit=5)

    f"Citation {i+1}:\n{c['content']}"

Generate a clinical MCQ about myocardial infarction.

Prevention Measure 4: Pre-Commit Hook Enforcement

✓ Solution Deployed

Location: .git/hooks/pre-commit

Purpose: Automatic enforcement on every git commit (blocks invalid content)

#!/bin/bash
# Pre-commit hook: Content Substance Validation

# Get staged files
STAGED_FILES=$(git diff --cached --name-only --diff-filter=ACM)

# Filter for MCQ/OSCE/Study Card files
CONTENT_FILES=$(echo "$STAGED_FILES" | grep -E '(mcqs|osces|study_cards)/.*\.json')

# Validate each file
VALIDATION_FAILED=0
for file in $CONTENT_FILES; do
    if ! scripts/validate_content_substance.sh "$file"; then
        VALIDATION_FAILED=1
    fi
done

# BLOCK commit if validation failed
if [ $VALIDATION_FAILED -eq 1 ]; then
    echo "❌ COMMIT BLOCKED: Placeholder content detected"
    echo "Fix issues and try again."
    exit 1  # Prevents git commit
fi

echo "✓ All content validation passed"
exit 0

7. Execution Approach: Agent OS Task Delegation

Architecture: Project Manager → Medical Expert Agents

1. Project Manager (PM Coordinator)

Receives user request → Analyzes scope → Routes to appropriate medical expert

2. Medical Expert Agent (MED-001 through MED-010)

Applies specialty-specific tools → Fetches RAG citations → Generates MCQ with LLM → Self-validates → Returns to PM

3. QA Expert Agents (QA-001, QA-002, QA-003)

Validates Australian compliance → Checks clinical accuracy → Verifies citations → Reports to PM

4. PM Coordinator Final Check

Aggregates results → Verifies quality gates → Approves commit OR rejects with feedback

Example: Generating Cardiology MCQs (290 items)

from src.agents.project_manager import ProjectManager
from src.agents.medical.med_001_cardiology import CardiologyExpert
from src.agents.qa.qa_003_rag_validator import RAGValidator

# 1. PM Coordinator receives task
pm = ProjectManager()
task = {
    "type": "generate_mcqs",
    "specialty": "cardiology",
    "count": 290,
    "topics": [
        "ACS variants", "Arrhythmias", "Heart failure",
        "Long QT syndrome", "Upper limb DVT", "Pulmonary edema"
    ]
}

# 2. PM routes to Cardiology Expert
cardio_agent = CardiologyExpert()
result = pm.delegate_task(
    agent=cardio_agent,
    task=task,
    constraints={
        "citations_required": 3,
        "rag_confidence_min": 0.70,
        "summary_required": True,
        "summary_length": (50, 200),
        "australian_compliance": True,
        "tools": ["ECG_interpretation", "GRACE_score", "TIMI_risk"],
        "fail_fast": True
    }
)

# 3. Cardiology Expert generates MCQs
for topic in task["topics"]:
    # Step 3a: Fetch RAG citations
    citations = cardio_agent.rag_query(
        topic=topic,
        limit=5,
        filters={"guideline": ["eTG", "AHA", "ESC"]}
    )

    if len(citations) < 3:
        # Fail-fast: Retry with different keywords
        citations = cardio_agent.rag_query_retry(topic)
        if len(citations) < 3:
            cardio_agent.log_error(f"Insufficient citations for {topic}")
            continue  # Skip this topic

    # Step 3b: Extract citation content
    citation_content = cardio_agent.extract_content(citations[:3])

    # Step 3c: Generate with LLM (specialty-specific prompt)
    mcq = cardio_agent.llm_generate(
        topic=topic,
        citation_content=citation_content,
        tools=["ECG_interpretation", "GRACE_score"],
        prompt_template="cardiology_mcq_v2"
    )

    # Step 3d: Self-validate (fail-fast)
    validation = cardio_agent.validate_mcq(mcq)
    if not validation.passed:
        # Retry generation with explicit fixes
        mcq = cardio_agent.regenerate_with_fixes(
            mcq, validation.errors
        )

    # Step 3e: Apply specialty tools
    if "ECG" in topic or "arrhythmia" in topic.lower():
        mcq = cardio_agent.add_ecg_image_placeholder(mcq)

    if "ACS" in topic or "infarction" in topic.lower():
        mcq = cardio_agent.add_grace_score_calculation(mcq)

    # Step 3f: Return to PM
    result.add_mcq(mcq)

# 4. QA Expert validation
qa_validator = RAGValidator()
qa_result = qa_validator.validate_batch(
    result.mcqs,
    tier_1_threshold=0.90
)

# 5. PM Coordinator final check
if qa_result.tier_1_approval_rate >= 0.70:
    pm.save_to_file(
        result.mcqs,
        "data-jan-26/mcqs/cardiology_290_mcqs.json"
    )
    pm.log_success(f"Generated {len(result.mcqs)} cardiology MCQs")
else:
    pm.log_warning(
        f"QA-003 Tier 1 approval rate: {qa_result.tier_1_approval_rate:.1%}"
    )
    pm.request_llm_review(qa_result.tier_2_mcqs)
