## Test Scenarios

### 1. Normal Load Test
- **Users**: 50 concurrent
- **Purpose**: Baseline performance
- **Metrics**: p50, p95, p99, success rate
- **Duration**: ~2-3 seconds

### 2. Peak Load Test
- **Users**: 100 concurrent (batched)
- **Purpose**: Maximum capacity validation
- **Metrics**: Same as normal load
- **Duration**: ~5-7 seconds

### 3. Rate Limiting Test
- **Attempts**: 15 (limit: 10)
- **Purpose**: Validate rate limit enforcement
- **Expected**: At least 5 blocked
- **Duration**: ~1-2 seconds

### 4. Connection Limit Test
- **Attempts**: 5 (limit: 3)
- **Purpose**: Validate connection tracking
- **Expected**: Exactly 3 allowed, 2 blocked
- **Duration**: ~1 second

### 5. Invalid Token Test
- **Attempts**: 20 invalid tokens
- **Purpose**: Security validation
- **Expected**: All 20 blocked
- **Duration**: ~1 second

**Total Runtime**: ~10-15 seconds
