## Technical Architecture (Recommended)

### Tech Stack

| Layer | Technology | Rationale |
|-------|-----------|-----------|
| **Web Frontend** | Next.js 14 + TypeScript | SEO, SSR, fast development |
| **Mobile Apps** | React Native (Expo) | Single codebase, team knows React |
| **Backend** | FastAPI (Python) | Your existing stack, fast performance |
| **Database** | PostgreSQL (Supabase) | ACID compliance, JSONB for flexibility |
| **Cache** | Redis (Upstash) | Sessions, rate limits, hot data |
| **Vector DB** | Qdrant (existing) | RAG for AI tutor |
| **Auth** | Clerk | Fast implementation, built-in features |
| **Payments** | Stripe | Best subscription support |
| **Hosting** | Vercel + Railway | Cost-effective, scales well |
