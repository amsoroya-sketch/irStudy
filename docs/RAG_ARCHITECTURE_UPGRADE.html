Stage 1: Query Processor

File: backend/src/ai/query_processor.py (new)

  • PubMedBERT: pritamdeka/S-PubMedBert-MS-MARCO (768-dim, fine-tuned for medical retrieval)
  • HyDE: Claude API generates hypothetical answer, embeds it for better semantic match

Stage 2: Hybrid Retriever

File: backend/src/ai/hybrid_retriever.py (new)

  • Dense Search: PubMedBERT vector similarity (top 50)
  • Sparse Search: BM25 keyword matching (top 50)
  • RRF Fusion: Reciprocal Rank Fusion combines both rankings
  • Qdrant Requirement: v1.10+ for hybrid search support

Stage 3: Reranker

File: backend/src/ai/reranker.py (new)

  • Cross-Encoder: ms-marco-MiniLM-L-6-v2 (300ms for 50 pairs)
  • Australian Boost: +30% score for eTG, RACGP, AMC, Talley sources
  • MMR Filtering: λ=0.5 balances relevance vs diversity

Stage 4: Citation Formatter

File: backend/src/ai/rag_service.py (updated)

  • Point ID Extraction: Links to Qdrant qdrant_point_id for verification
  • Page Verification: Ensures page numbers exist in source metadata
  • Australian Format: "eTG Cardiovascular 5.2.1 (2024), p. 142"
