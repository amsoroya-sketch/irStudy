🎨 System Architecture

7-Layer Architecture Diagram
Click image to view full size (300 DPI)

Layer Breakdown:

Layer 1: Browser / Client

React 18 application running in user's browser. Handles UI rendering, user interactions, and client-side routing.

Layer 2: App Router

React Router v6 with lazy loading. Manages navigation, route protection, and code splitting.

Layer 3: Protected Route Guard

Authentication checkpoint. Checks for JWT token in localStorage before allowing access to protected pages.

Layer 4: Page Component

MCQBrowser.tsx - Manages state, filters, pagination. Uses React Query for server state management.

Layer 5: API Client

Axios instance with request/response interceptors. Handles authentication headers and token refresh.

Layer 6: Backend API

FastAPI endpoints with dependency injection. Validates JWT, processes requests, queries database.

Layer 7: Database

PostgreSQL with SQLAlchemy ORM. Stores MCQs, user data, attempts, and progress.

🎯 Key Design Patterns

1. Higher-Order Component (HOC) Pattern

Used in: ProtectedRoute

Purpose: Wrap route components to add authentication checks

Pattern: ProtectedRoute HOC 
// Wraps child components with auth check
function ProtectedRoute({ children }) {
  const { isAuthenticated } = useAuth();
  
  if (!isAuthenticated) {
    return <Navigate to="/login" replace />;
  }
  
  return children;
}

2. Custom Hook Pattern

Used in: useAuth, useQuery

Purpose: Encapsulate reusable stateful logic

Pattern: Custom Hook 
// Custom hook for authentication
function useAuth() {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth must be used within AuthProvider');
  }
  return context;
}

3. Interceptor Pattern

Used in: Axios request/response interceptors

Purpose: Centralize cross-cutting concerns (auth, error handling)

Pattern: Request Interceptor 
// Automatically adds auth header to all requests
axiosInstance.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('accessToken');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  }
);

4. Dependency Injection Pattern

Used in: FastAPI endpoint dependencies

Purpose: Decouple authentication from business logic

Pattern: Dependency Injection (FastAPI) 
# FastAPI automatically calls get_current_active_user
@router.get("/")
async def list_mcqs(
    current_user: User = Depends(get_current_active_user),
    db: Session = Depends(get_db)
):
    # If we reach here, user is authenticated
    mcqs = db.query(MCQ).all()
    return mcqs
